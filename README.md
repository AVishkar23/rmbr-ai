# Rmbr AI - Memory Companion

A modern, minimal Notion-like landing page for "Rmbr AI" - an emotionally intelligent AI-powered digital companion designed to help people preserve and interact with the voices and memories of loved ones, mentors, or even their past or future selves.

## 💝 What is Rmbr AI?

Rmbr AI is more than just another chatbot. It's a deeply human tool for emotional healing and connection that allows users to:

- **Upload memories**: Share photos, voice clips, and written messages
- **Create digital companions**: AI learns their tone, style, and personality
- **Have meaningful conversations**: Say goodbye, reconnect with inner child, seek guidance
- **Heal and grow**: Navigate grief, find closure, and build emotional resilience

## 🚀 Features

- **Modern Design**: Clean, minimalist interface inspired by Notion's design principles
- **Emotionally Intelligent**: AI that captures the essence of loved ones
- **Privacy First**: Encrypted data, never used for external training
- **Responsive Layout**: Fully responsive design that works on all devices
- **Smooth Animations**: Subtle animations and transitions for enhanced user experience
- **Interactive Elements**: Hover effects, button animations, and smooth scrolling
- **Mobile-First**: Optimized for mobile devices with hamburger menu
- **Performance Optimized**: Fast loading with minimal dependencies
- 🎤 **Voice Cloning**: Clone voices using ElevenLabs or A2E.ai technology
- 🤖 **AI Conversations**: Natural conversations powered by OpenAI's GPT-4
- 🎭 **Avatar Generation**: Create talking avatars with A2E.ai
- 📝 **Personality Analysis**: Understand communication patterns from text
- 🧠 **Memory System**: Store and recall important memories and context
- 🎯 **Contextual Responses**: Relevant responses based on stored memories
- 🌐 **Real-time Audio**: Instant voice synthesis for responses

## 🎨 Design Elements

- **Color Scheme**: Warm red/pink gradient theme (#e11d48 to #be185d) for emotional connection
- **Typography**: Inter font family for modern, readable text
- **Icons**: Font Awesome icons for consistent visual elements
- **Layout**: CSS Grid and Flexbox for responsive layouts
- **Animations**: CSS animations and JavaScript-powered interactions

## 🎨 Customization

### Colors
The main color scheme can be modified in `styles.css`:
- Primary: `#e11d48` (warm red)
- Secondary: `#be185d` (deeper red)
- Text: `#37352f` (dark gray)
- Background: `#ffffff` (white)
- Accent: `#fef2f2` (light pink)

### Content
- Update text content in `index.html`
- Modify icons by changing Font Awesome classes
- Adjust animations in `script.js`
